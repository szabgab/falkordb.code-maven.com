---
name: increase test coverage
description: >-
    Run the tests to see which part of the code was covered while they ran
    and add more test to cover other parts as well.
---

* Run `cover -test` to generate a test coverage report.
* Look at the output on the terminal and also in the `cover_db` folder for the reporst.
* Write tests that will exercise functions that were not covered yet (The 'sub' column)
* Write tests that will exercise statements that were not covered yet. (The 'stm' column)
